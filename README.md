# BookStore

Сайт для покупки книг: каталог с подборками, детальные карточки книг и форма быстрого заказа.

**Демо:** [ссылка, если выложишь на GitHub Pages или Vercel]

## Возможности
- Каталог с подборками книг
- Детальная карточка книги
- Форма быстрого заказа
- Адаптивный дизайн, тёмная тема

## Стек
React, Vite, Tailwind CSS

## Запуск
npm install
npm run dev

## Структура
- `src/` — компоненты и страницы
- `db/` — данные каталога
- `public/` — статические файлы
